Ordinary project dependencies may be installed without sudo; use a Python virtualenv when needed.

Create an untracked `handoff-marker.txt`, modify a tracked file, and make one unpushed task commit on your disposable branch. Report completion through the assigned task's supported Paperclip callback with your scoped run credentials. Do not push or create a PR in the initial test.
